College Project Overview

First-Year Engineering Academic Submission

Academic Year 2026
Project Title: Restaurant Food Waste Management Platform
Project Objective: To develop a functional, visually professional web application that assists restaurant managers in recording, monitoring, and analysing food wastage by ingredient category, department, and cause. The platform pinpoints high-cost losses and generates actionable, rule-based recommendations to improve kitchen efficiency and environmental sustainability.
Problem Statement: Commercial restaurants produce substantial food waste due to inaccurate demand forecasting, storage spoilage, prep errors, and unsold prepared items. Standard restaurants operate on thin 3%–6% profit margins, and food waste directly erodes both financial viability and sustainability goals. This web platform delivers clear visibility without expensive enterprise software.
Technology Stack: HTML5 Semantic layouts, accessible forms, data tables, structural containers
CSS3 Responsive flexbox & grid, custom CSS variables, dark/light theme, modern card design
Vanilla JavaScript DOM manipulation, mathematical aggregations, filtering, CSV export, rule evaluation
Browser Local Storage Client-side JSON data persistence with zero external server dependencies
Application Architecture: Single-Page Application (SPA) architecture running 100% locally in the browser by opening index.html. Zero backend frameworks (No Node.js, Python, PHP, or SQL servers needed).
